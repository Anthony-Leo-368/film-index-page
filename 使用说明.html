胶卷索引软件 · 使用说明

这是什么

一个在你自己电脑上本地运行的胶卷整理与索引工具：用 Excel 当数据库，用浏览器当界面。
数据不上传、不联网，全部存在你自己的硬盘里。

一句话上手

把软件文件夹放进你的胶卷根目录 → 双击 010_启动Mac.command → 浏览器自动打开 → 点「➕ 新增条目」开始录入。

二、运行环境

兼容性说明

目前只在 macOS 上完整测试过，Windows 版本可用但尚未测试，遇到问题请反馈。

  • macOS：系统自带 Python 3，无需额外安装。图片降采样用系统自带的 sips。
  • Windows：需要先安装 Python 3（安装时务必勾选 Add Python to PATH）。图片降采样用系统自带 PowerShell。
  • 浏览器建议用 Safari（macOS 的「打开文件夹」功能依赖 Safari；Chrome / Edge 出于安全策略无法跳转本地文件夹）。

三、目录结构与安装

3.1 需要的目录结构

软件靠「文件夹层级」找到你的胶卷。把软件文件夹 000_Film_Index_Page 放进你的胶卷根目录，和各卷文件夹并排：

~~~text

我的照片/FILM/ ← 胶卷根目录（名字随意）

├─ 000_Film_Index_Page/ ← 软件本体（放这里）

│ ├─ 010_启动Mac.command

│ ├─ 011_启动Win.bat

│ └─ assets/ ← 数据与程序都在这里

├─ 001_index 3302_FOMAPAN 100_240402-240403/ ← 名字必须与软件生成的一致

│ ├─ 010_scan/ ← 冲扫店的扫描图

│ ├─ 011_scanPost/ ← 扫描后期图（如 TIFF → LR 导出 jpg）

│ ├─ 020_cam/ ← 翻拍 RAW / 去色罩源文件（软件不读取）

│ └─ 021_camPost/ ← 翻拍后期成片（软件读取）

└─ 002_index ...

~~~

子目录名是写死的，请勿改名

软件只认这三个名字，必须完全一致，改成别的名字就找不到图片：
- 010_scan：冲扫店发来的扫描图（jpg）
- 011_scanPost：扫描后期图——例如自己扫了 TIFF，用 Lightroom 导出成 jpg 放这里
- 021_camPost：翻拍后期成片——翻拍处理完、导出的可看照片

另有 020_cam：用于存放翻拍的相机 RAW 与去色罩源文件；这类文件无法直接观看，软件故意不读取它。请把处理后的成片导出到 021_camPost。

预览取图顺序：扫描 = 011_scanPost → 010_scan，翻拍 = 021_camPost，可在预览面板切换来源。

胶卷文件夹名必须与软件生成的一致

各卷文件夹名（例如 001_index 3302_FOMAPAN 100_240402-240403）由软件按「序号 / 编号 / 型号 / 拍摄开始 / 拍摄结束」自动生成，格式为：
<序号>_index <编号>_<型号>_<YYMMDD>[-<YYMMDD>]
磁盘上的文件夹必须与这个名字完全一致（含空格），软件才能定位到里面的图片；名字对不上时，列表里还能列出行，但点「预览」会提示找不到图片。
唯一例外：导出 Index Print 时，若名字对不上，软件会退一步按「<序号>_index」前缀去找文件夹。
建议流程：先在软件里新增条目 → 复制它生成的文件夹名 → 再据此命名磁盘上的文件夹。

三之二、正确使用顺序（推荐）

很多用户第一次上手时会先建文件夹再登记，其实更顺的做法是先在网页里登记，再建文件夹，最后移照片。

  1. 放好软件：把「000_Film_Index_Page」整个文件夹放进你的「胶卷根目录」，和各卷文件夹并排。
  2. 在网页里登记胶卷：点右上角「＋ 新增条目」，填序号（3~4 位数字、唯一）、胶卷型号（必填）、拍摄开始（必填）等，填完点「确定」。
  3. 建文件夹：在编辑／新增条目窗口底部点「📁 创建文件夹」，会按你填的信息自动生成这一卷的文件夹（例如 124_index 1234_FOMAPAN 100_261013）。再点「📁 添加子文件夹」勾选要建的标准子文件夹 —— 已经存在的会自动置灰不可选，点「全选可创建项」再「创建选中的」即可。
  4. 把照片移进来：最后把要整理的照片移动到对应子文件夹。放好后回到网页点该行「预览」就能看图。
子文件夹放什么
010_scan扫描原片 —— 店扫／平板扫出来的原始文件　★ 只有扫描件的话，只建这个就够
011_scanPost扫描后期 —— 修图调色后导出的成品
020_cam翻拍原片 —— 用相机／手机翻拍的原始文件
021_camPost翻拍后期 —— 翻拍后修图导出的成品

只有扫描件的情况（大多数人）：建子文件夹时只勾 010_scan，照片全部放进它里面就行。

先把文件夹建好再移照片最省事；顺序反了也不会出错，只是要自己手动建文件夹。

五、功能详解

5.1 目录视图

  • 每一行是一卷胶卷；默认按序号从大到小排（最新一卷在最上面）。点表头可按该列排序，再点一次切换升 / 降序。
  • 列宽可以拖动；双击列边缘可按内容自动适应宽度。
  • 右侧「操作」列：预览（展开该卷图片）、编辑（修改）、打开文件夹（用访达打开该卷目录）。
  • 显示哪些列、列的顺序，都可以在 ⚙ 设置 → 显示 里调整。

5.2 搜索

在搜索框输入即可实时筛选。常用语法：

型号:"Gold 200"值里有空格时用引号

  • 搜索框右边的日期搜索模式决定区间怎么算：部分包含（默认，只要时间段有重叠）或完全包含。

5.3 日历视图

1. 视图切换：左上角在 📋 目录视图 / 🗓 日历视图 之间切换。

2. 日历工具栏：切换 周视图 / 月视图，调整「每行」显示多少，用 ◀ 今天 ▶ 跳转，右侧显示当前日期范围。

3. 按相机分道：每台相机一整行；每一卷是一条横条，长度 = 拍摄区间。同一天的胶卷一目了然，特别适合看「哪段时间拍得多、哪台机器在轮换」。

5.4 预览与大图

  • 点某行的「预览」展开该卷所有图片；再点「收起」关闭。
  • 面板顶部是预览来源：扫描 / 翻拍 一键切换。
  • 只对当前这一卷生效，刷新页面后回到设置里的默认来源。
  • 某卷只有单一来源时，另一种按钮会置灰，高亮的是该卷实际使用的来源。
  • 点任意缩略图进入大图查看器：

大图查看器支持：放大 / 缩小、左转 / 右转、复位、上一张 / 下一张、下载、打开所在位置；也可以用鼠标拖动、滚轮缩放、双击放大。

为什么预览有时要等一两秒

预览用的是降采样小图并做了缓存（存在系统缓存目录，不占机械盘）。第一次看某卷时会现场生成，之后就很快了。

5.5 新增 / 编辑 / 删除 / 撤回

点「➕ 新增条目」打开表单（对应上图编号）：

1. 胶卷型号（必填）：可直接输入关键字筛选，从下拉里选。

2. 相机：同上，可输入筛选。

3. 拍摄开始（必填）/ 拍摄结束：日期格式 YYYY-MM-DD。

4. 拍摄状态：拍摄中 / 待冲洗 / 冲洗中 / 待归档 / 已归档。

5. 选项设置：型号或相机不在选项库里时，可以点这里去补。

6. 确定 / 取消：提交前会弹差异确认，列出你改了哪些字段。

几个必须知道的规则

- 序号是主键：3~4 位数字，不能重复。
- 型号和拍摄开始是必填；不填拍摄开始的条目不会出现在列表里。
- 输入的型号 / 相机若不在选项库，输入框会标红；点确定会问你要不要跳去「选项设置」添加，选「取消」会中止提交并留在表单。
- 删除需要手动输入屏幕上的随机确认词，属于高危操作，请谨慎。

30 秒内可撤回

每次增 / 改 / 删之后，底部会出现撤回条，30 秒内可以撤回上一次操作（服务端窗口为 180 秒）。

5.6 拍摄状态与整行高亮

  • 目录视图会按「拍摄状态」给整行铺浅色底 + 左侧色条；「已归档」不高亮（保持清爽）。
  • 默认颜色：拍摄中 = 红，待冲洗 / 冲洗中 = 黄，待归档 = 灰。
  • 颜色可以自定义：⚙ 设置 → 🎞 拍摄状态颜色。
  • 日历视图不受状态颜色影响。

5.7 选项设置

  • 打开方式：表单右上角「⚙ 选项设置」，或设置面板里的入口。
  • 三列分别是相机选项 / 画幅选项 / 胶卷型号选项，每行一项。
  • 保存时自动去空行、去重、超上限截断，并写回 Excel 的「选项」工作表；之后表单下拉立即生效（已填内容保留）。

5.9 导出 Index Print（与底片放在一起的可打印索引）

它是干什么用的

Index Print 是打印出来和底片收纳在一起的索引页：每卷一张，上面有卷名、机型、拍摄 / 冲扫日期，以及整卷照片的缩略图。整理底片袋、翻找某一卷时，拿这张纸一眼就能对上，不用再翻电脑。

1. 点顶部「🖨 导出 Index Print」。

2. 勾选要导出的胶卷（单选、Shift 连选、Ctrl / ⌘ 点选；也可「全选」「反选」「仅选未生成」）。

3. 设置清晰度、JPEG 质量、竖图旋转、是否跳过已生成。

4. 点「开始生成」，每卷生成一个与其文件夹同名的 .docx，输出到 FILM/000_INDEX PRINT/（可在设置里改）。

5. 版式：135 每行 4 张、宽 4.19cm；120 每行 3 张、宽 5.59cm；竖图自动旋转。

冲洗店给的「整卷缩略图」会被自动排除，不会导出到 Index Print。

六、数据、备份与恢复

6.1 文件都在哪

文件 / 目录作用
assets/films.xlsx核心数据库，所有胶卷信息都在这里（Excel 可直接打开查看）
assets/settings.json你保存的设置
assets/snapshot.json程序生成的快照，一般不用管
assets/backup/备份（编辑备份 10 份 + 每日备份 30 份）
assets/log/日志，按天一个文件，保留 30 天
系统缓存目录预览缩略图缓存（macOS：~/Library/Caches/FilmIndex）

6.2 备份与恢复

  • 自动备份：启动时、每天首次、每次增删改，都会在 assets/backup/ 留一份带时间戳的备份。
  • 恢复：找到 backup/films_<时间戳>_<类型>.xlsx，复制回 assets/films.xlsx 覆盖即可。
  • 撤回：界面里的撤回条（30 秒内）用的是 backup/_undo.xlsx。

6.3 日志

每次启动、增删改、缩略图生成、导出都会写日志。出问题时，打开 assets/log/ 下当天的文件即可排查。

七、常见问题（FAQ）

- 双击启动脚本没反应 / 提示来自身份不明的开发者？

macOS：右键该文件 → 打开 → 再点「打开」；或到 系统设置 → 隐私与安全性 点「仍要打开」。

- 页面能打开，但没有数据 / 一直显示「共 0 卷」？

多半是「拍摄开始」没填，或序号不是 3~4 位数字。软件只收录序号为 3~4 位数字、且拍摄开始非空的条目。

- 修改被拒绝，提示「检测到 Excel 正打开 …」？

请先关闭正在打开 films.xlsx 的 Excel / LibreOffice，再操作。若确认要强写，可按提示强制继续（但你之后在 Excel 里保存会覆盖它）。

- 图片不显示 / 提示找不到目录？

检查这一卷里是否有 010_scan / 011_scanPost / 021_camPost 子目录，以及图片扩展名是否为 jpg / jpeg / png / heic / heif / hif。

- 「打开文件夹」点不动？

该功能必须用 Safari；Chrome / Edge 禁止网页跳转到本地文件夹。

- 预览很慢？

- Windows：v0.4.5 起缩略图边生成边显示（不再等整卷跑完才一起出现），并且正在看的那几张优先做、多进程并行；首次看某卷仍需要几秒，之后走缓存秒开。
- macOS 上第一次看某一卷会现场生成缩略图（几秒内），再看同一卷走缓存，基本秒开。
- 可以把 预览质量档位调低、缩略图缓存上限调大；系统缓存目录尽量放在 SSD。
- v0.4.0 及更早的 Windows 版最慢（每张图起一个 PowerShell 进程），请尽快升级。

- 改了代码之后要做什么？

- 改了 build_html.py → 必须重新运行 python3 assets/build_html.py 生成 index.html。
- 改了 worker.py → 必须重启服务（后端只在启动时加载）。
- 直接改 index.html 会在下次生成时被覆盖，白干。

- 数据会不会丢？

有自动备份 + 撤回机制，但没有版本控制。重要数据请定期把 assets/films.xlsx 单独复制一份到别处。

文件夹名自动同步 / 一键创建（v0.4.9 起）

每个弹窗顶部都会显示「有没有匹配到文件夹」

打开「新增 / 编辑」「确认提交」「删除」这类针对某一条胶卷的弹窗时，标题下方都会有一条状态：
- 绿底 📁 已匹配到文件夹：xxx —— 正常；
- 红底 ⚠ 未找到对应文件夹（按当前信息应为 xxx） —— 硬盘上还没有这一卷；
- 黄底 ✏️ 信息已修改：保存后会把文件夹名同步改为「B」（当前硬盘上是「A」） —— 你刚改了会影响文件夹名的字段；
- 红底 ⚠ 文件夹名与当前信息不一致 —— 保存后也会自动同步；
建好 / 改好文件夹后状态会立刻刷新，不用关掉重开。

编辑后自动同步文件夹名（保存即改）

修改某卷的胶卷编号 / 胶卷型号 / 拍摄开始 / 拍摄结束后，如果算出来的文件夹名变了，保存时会直接把硬盘上的真实文件夹改名，不再单独弹窗问你。格式仍是 <序号>_index <编号>_<型号>_<YYMMDD>[-<YYMMDD>]。
- 改之前就能看见：编辑页顶部状态条会动态提示「✏️ 信息已修改：保存后会把文件夹名同步改为「新名」（当前硬盘上是「旧名」）」；
- 硬盘上找不到这一卷的文件夹 → 不改名，只提示；
- 新名字对应的文件夹已存在 → 拒绝改名并提示，绝不覆盖。

新增条目：一键建文件夹

「➕ 新增条目」表单底部有：
- 📁 创建文件夹：按当前填写的序号 / 编号 / 型号 / 拍摄开始算出文件夹名并创建。可点时是蓝色；如果该卷文件夹已经存在，按钮会变成灰色虚线框并显示「📁 文件夹已存在」，一眼就能看出不能点。
- 🔄 同步文件夹名：手动把硬盘上的文件夹改成与表格一致，用于修历史遗留的不一致。

注：v0.4.9 起暂不提供「同时创建标准子文件夹」（子文件夹并非每卷都有，容易显得冗余）；后端接口保留了该参数，以后需要可随时恢复。

新增保存后会主动问你要不要建文件夹

新增条目保存成功后，如果当前信息在硬盘上没有匹配到文件夹，软件会弹窗询问是否现在创建（创建前会显示完整文件夹名）。

> 以上操作都只在服务模式（双击启动脚本打开）下可用，执行前都会弹确认框。

*本文档对应版本 v1.0.3。*

放进「应用程序」—— 用 Spotlight / 启动台秒开

发布包里的 Film Index Page.app 是一个标准的 macOS 应用。

怎么装：把它拖进「应用程序」文件夹即可。

怎么打开：Cmd + 空格 输入 film 回车，或到「启动台」点图标。

启动逻辑（第一次会问你一次）：首次打开会弹出文件夹选择框，让你指定「胶卷索引信息」所在目录 —— 选中那个含有 010_启动Mac.command 和 assets 的文件夹即可；选好后自动记住，以后秒开。若日后目录被移动，软件会检测到并自动重新弹框让你选，不用手动改配置。也可以把 .app 直接放进「胶卷索引信息」文件夹里，这样它自己就能认出位置，连第一次选择都省了。

怎么关闭：软件在一个终端窗口里运行本地服务，关掉那个窗口即停止服务，不会在后台留下进程。

若提示「无法打开，因为来自身份不明的开发者」：这是下载来的 .app 被加了隔离标记。在「应用程序」里右键该 .app →「打开」→ 再点「打开」，之后即可正常双击。
