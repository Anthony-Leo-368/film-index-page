# 胶卷索引页面 (film-index-page)

> 一个本地运行、用 Excel 当数据库、用浏览器当界面的胶卷整理与索引工具。
> **数据不上传、不联网，全部存在你自己的硬盘里。**

当前版本 **v1.0.3**　·　仅非商业使用（见 [LICENSE](LICENSE)）　·　macOS 已完整测试，Windows 可用

---

## 这是什么

拍完胶卷之后最麻烦的是整理：这一卷是哪台机拍的、什么时候拍的、冲到哪一步了。
这个工具就是干这个的——把每一卷收进一张表，用文件夹名串起硬盘上的照片。

**纯 Python 标准库 + 单文件前端**，没有第三方依赖、没有构建步骤，下载就能跑。

## 功能

| 功能 | 说明 |
|---|---|
| 📋 目录视图 | 一卷一行：序号、编号、型号、画幅、相机、拍摄起止、备注、文件夹名。点表头排序，列可显示/隐藏/调顺序 |
| 🎞 胶卷图标 | 内置 213 款胶卷型号的实物图，目录视图每条左边显示，型号下拉框也带图标 |
| 🔍 悬停高清 | 鼠标停在图标上，弹出该胶卷的高清大图（只在悬停时加载，不拖慢列表）|
| 🗓 日历视图 | 按拍摄时间把每卷画成一条横条，可按相机分道，周视图 / 月视图随意切 |
| 🖼 整卷预览 | 点「预览」看整卷缩略图；点开可放大、拖拽、旋转、下载原图 |
| 🎬 拍摄状态 | 拍摄中 / 待冲洗 / 冲洗中 / 待归档 / 已归档，整行上色，颜色可改 |
| 🔍 搜索 | 关键字、`列:值`、`-排除`、日期范围，多个条件空格隔开 |
| 📁 文件夹自动化 | 改了编号/型号/拍摄日期，保存时自动同步硬盘上的文件夹名；新增条目可一键创建文件夹 |
| 🖨 Index Print | 勾选胶卷批量导出可打印的 docx，每卷一张索引页 |

## 下载 / 安装

**国内下载（坚果云，推荐）**：https://www.jianguoyun.com/p/DSKDf6cQ07D8CxjElasGIAA

1. 解压得到的 `000_胶卷索引信息` 文件夹，**放进你的胶卷根目录**（里面是各个 `xxx_index ...` 胶卷文件夹）
2. **macOS**：双击 `010_启动Mac.command`
   **Windows**：双击 `011_启动Win.bat`
3. 浏览器会自动打开界面；首次运行会用 `assets/template.xlsx` 自动生成一份空白数据库

> Windows 上如果打开预览较慢，是缩略图在首次生成；第二次打开会快很多。

## 正确使用顺序（推荐）

很多用户第一次上手会先建文件夹再登记，其实更顺的做法是 **先在网页里登记，再建文件夹，最后移照片**。

1. **放好软件** —— 把 `000_Film_Index_Page` 整个文件夹放进你的「胶卷根目录」，和各卷文件夹并排。
2. **在网页里登记胶卷** —— 点右上角「＋ 新增条目」，填序号（3~4 位数字、唯一）、胶卷型号（必填）、拍摄开始（必填）等，点「确定」保存。
3. **建文件夹** —— 编辑／新增条目窗口底部点「📁 创建文件夹」，会按填的信息自动生成这一卷的文件夹（如 `124_index 1234_FOMAPAN 100_261013`）。再点「📁 添加子文件夹」勾选标准子文件夹 —— 已存在的会自动置灰不可选，点「全选可创建项」再「创建选中的」即可。
4. **把照片移进来** —— 最后把照片移动到对应子文件夹，回到网页点该行「预览」即可看图。

| 子文件夹 | 放什么 |
|---|---|
| `010_scan` | 扫描原片（店扫 / 平板扫的原始文件）★ **只有扫描件的话，只建这个就够** |
| `011_scanPost` | 扫描后期（修图调色后导出的成品）|
| `020_cam` | 翻拍原片（相机 / 手机翻拍的原始文件）|
| `021_camPost` | 翻拍后期（翻拍后修图导出的成品）|

**只有扫描件的情况（大多数人）**：建子文件夹时只勾 `010_scan`，照片全部放进它里面即可。

> 先把文件夹建好再移照片最省事；顺序反了也不会出错，只是要自己手动建文件夹。

## 目录结构

```
000_胶卷索引信息/
├── 010_启动Mac.command        启动脚本（macOS）
├── 011_启动Win.bat            启动脚本（Windows）
├── 030_手动更新索引.command   手动重建快照
├── 031_手动更新索引.bat
├── 使用说明.txt / .html
└── assets/
    ├── worker.py              后端：快照 / 本地服务 / 缩略图
    ├── build_html.py          前端生成器 → index.html
    ├── index.html             生成好的页面
    ├── template.xlsx          空白数据库模板（首次运行自动复制成 films.xlsx）
    ├── index_template.docx    Index Print 的 docx 模板
    ├── film_icons/            型号图标（96×77，列表用）
    └── film_icons_hd/         型号图标高清母版（悬停预览用）
```

**你自己的数据**（不进版本库）：`films.xlsx`、`snapshot.json`、`settings.json`、`log/`、`backup/`
这些都在 `.gitignore` 里排除了。

## macOS 应用（Spotlight / 启动台启动）

发布包里的 **Film Index Page.app** 是一个标准 macOS 应用。

**安装**：把它拖进「应用程序」文件夹即可。

**打开**：⌘ + 空格 输入 film 回车，或到「启动台」点图标。

**启动逻辑**：
- 首次打开会弹出文件夹选择框 —— 指定「000_胶卷索引信息」所在目录（里面应有 010_启动Mac.command 和 assets）。选好后自动记住。
- 之后直接用记住的位置，秒开。
- 若目录被移动（换硬盘 / 改文件夹名），会自动重新弹框让你选，无需手动改配置。
- 也可以把 .app 直接放进软件文件夹内 —— 它能自己认出位置，连首次选择都省了。

**关闭**：软件在终端窗口中运行本地服务，关掉那个窗口即停止服务，不会残留后台进程。

**提示「无法打开，因为来自身份不明的开发者」**：这是下载来的 .app 带有隔离标记。在「应用程序」里右键该 .app →「打开」→ 再点「打开」，之后即可正常双击。
