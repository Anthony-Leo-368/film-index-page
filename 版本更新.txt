- v1.0.4（2026-10-16）
  - 新增：文件夹操作实时生效 —— 点「创建文件夹」「添加子文件夹」「同步文件夹名」立刻在硬盘生效，新增条目和编辑条目行为完全一致（不再「等确定才建」）。
  - 新增：取消 / 撤回时自动还原文件夹 —— 新建的移入废纸篓（随时可恢复）、改名的改回原名、删除的找回原位。两个入口共用同一套文件夹操作日志。
  - 优化：新增模式下点「添加子文件夹」，也会显示硬盘上真实的子文件夹状态（已存在的自动置灰，不会重复创建）。
  - 修复：新增条目时第一次点「创建文件夹」，「添加子文件夹」按钮不出现（要再点一次才行）—— 表单刷新会把刚显示的按钮又隐藏回去。
  - 修复：新增模式下点「添加子文件夹」误报「请先点创建文件夹」。
  - 说明：v1.0.3 的「创建文件夹改为保存后生效」在本版被取代为「实时生效 + 取消回滚」，操作更直观。


- v1.0.3（2026-10-15）
  - 新增：编辑 / 新增条目时可一键「添加子文件夹」——内置 010_scan（扫描原片）、011_scanPost（扫描后期）、020_cam（翻拍原片）、021_camPost（翻拍后期）四个标准子文件夹；已存在的自动置灰不可选，支持一键全选。
  - 新增：新增条目时创建文件夹与子文件夹改为「保存后生效」——在新增界面点创建只是先记下，取消添加不会在硬盘留下空文件夹。
  - 优化：新增条目的建文件夹确认合并为一次（去掉原来保存后的二次询问弹窗），第一屏直接显示将要创建的文件夹名与子文件夹。
  - 新增：软件图标改为矢量图重绘（米色底 + 珊瑚色胶卷暗盒 + 灰色片头），16px 到 1024px 都清晰。
  - 新增：macOS 应用包 Film Index Page.app —— 拖进「应用程序」后可用 Spotlight（Cmd+空格）或启动台直接打开；启动时会自动记住软件目录，找不到时弹出文件夹选择框让用户指定，选好后记住。
  - 优化：应用在可见的终端窗口中运行服务 —— 关掉窗口即停止服务，不会残留后台进程，程序坞也不会一直显示「正在打开」。
  - 修复：子文件夹相关的若干问题（前端变量未定义、后端参数被转成布尔值导致只建不全、保存时过早清空待建列表）。
  - 更名：软件文件夹统一命名为 000_Film_Index_Page，放在胶卷根目录里会排在所有卷文件夹最前面。
  - 说明：本版含新增功能与修复，不涉及数据格式变更，可从任意旧版本直接覆盖升级。

  - 版本号改为胶囊样式；鼠标悬停显示：当前版本更新内容（读自本文件）+ GitHub 开源地址 + 坚果云下载链接 + 小红书 ID。

  - 操作列重构：按钮按文字内容定宽、高度统一 24px、居中排列；列宽固定 236px，不再自适应浮动。主操作按钮取消品牌蓝，统一灰色。
  - 画幅信息改为圆角胶囊，并跟随所在行的拍摄状态着色（与行底色区分）。
  - 提示框逻辑理顺：撤回条出现时提示框自动上移避免重叠；提示框按类型加左侧色条；状态切换类提示不再弹出；引导说明仅首次显示。
  - 移除：主题色设置项、预览宽度数值显示、「（按 xx 排序）」后缀、「服务模式」文字。
  - 修复：目录视图滚动到中部或回弹后表头消失（滚动容器是 #wrap，sticky 的 top 需相对它计算，并禁用回弹）；展开预览时读取进度多算一张（36/37）；操作按钮撑出列宽；删除按钮悬停变白不可见。
  - 新增软件图标：K5「胶卷盒 + 片条」造型，输出 AppIcon.icns 与 16~1024px 全套 PNG（assets/icon/）。

- v0.4.9_beta（2026-10-09）
  - 编辑胶卷编号 / 型号 / 拍摄开始 / 拍摄结束后，若文件夹名变了，**保存时直接**把硬盘上的真实文件夹改名（不再单独弹窗确认）。

  - 硬盘上找不到该卷文件夹、或新名字的文件夹已存在时，不改名并给出提示（绝不覆盖）。
  - 新增条目表单底部新增「📁 创建文件夹」；该卷文件夹已存在时按钮自动置灰。
  - 新增条目保存成功后，若没有匹配到文件夹，会主动询问是否现在创建。
  - 「📁 创建文件夹」可点时是**蓝色**；文件夹已存在时变**灰色虚线框 + 文字改成「📁 文件夹已存在」**，一眼可辨不可点。
  - **暂不提供**「同时创建标准子文件夹」（子文件夹并非每卷都有，容易冗余）；后端仍保留 subs 参数，以后可随时恢复。
  - 另有「🔄 同步文件夹名」按钮；新增 / 编辑 / 确认提交 / 删除弹窗顶部都会显示有没有匹配到文件夹。

  - **修复**：从列表点「编辑」进入时顶部状态条不显示文件夹信息（该入口直接调 openForm，绕过了状态刷新）；现在所有入口统一，且在 openForm 末尾无条件刷新一次。
  - 删除条目时可勾选「同时删除硬盘上的文件夹」（默认**不勾选**）；勾选后会再确认一次，文件夹移入**废纸篓 / 回收站**（可恢复），并给出结果提示。
