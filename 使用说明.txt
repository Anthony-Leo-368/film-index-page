================================================
  胶卷索引 · 使用说明（v1.0.4）
  作者：Esc. X-ray
================================================

【这是什么】
一个在你电脑本地运行的胶卷整理与索引工具：用 Excel 当数据库，用浏览器当界面。
可以做到：列出所有胶卷、看某一卷的扫描/翻拍图、按拍摄时间看日历、搜索筛选、
在网页里新增/编辑/删除条目、给胶卷标「拍摄状态」、把整卷导成可打印的 Index Print。
数据全部存在你自己的电脑上，不联网、不上传。

【运行前准备】
1. 准备一个用来放胶卷的文件夹（下面叫「胶卷根目录」，例如 我的照片/FILM）。
2. macOS 自带 Python 3，无需安装；Windows 需要先安装 Python（见下）。

【把工具放到哪里】
把本文件夹「000_Film_Index_Page」整个放进你的「胶卷根目录」里，和各卷文件夹并排（同级）。

【第一次启动 · macOS（已测试）】
1. 双击 010_启动Mac.command。
   · 若提示「无法打开，因为来自身份不明的开发者」：
     右键该文件 → 打开 → 再点「打开」；或到「系统设置 → 隐私与安全性」点「仍要打开」。
   · 第一次启动会自动生成一个空白数据库 films.xlsx，不会删除你已有的任何文件。
2. 终端里会显示一个地址（http://127.0.0.1:xxxxx/），并自动用 Safari 打开页面。
3. 用完直接关闭那个终端窗口，服务就停止了，数据不会丢失。

【第一次启动 · Windows（尚未充分测试）】
1. 到 python.org 下载并安装 Python 3.x，安装时务必勾选「Add Python to PATH」。
2. 双击 011_启动Win.bat。

【正确使用顺序 · 一共四步】

 第 1 步 · 放好软件
   把本文件夹「000_Film_Index_Page」整个放进你的「胶卷根目录」里，
   和各卷文件夹并排（同级）。

 第 2 步 · 在网页里登记胶卷
   启动后点右上角「＋ 新增条目」，填好：
     · 序号（3~4 位数字、唯一）
     · 胶卷型号（必填，可直接输关键字筛选）
     · 拍摄开始（必填）
     · 其余项（相机 / 画幅 / 冲扫 / 拍摄状态等）按需填
   填完点「确定」保存。拍摄状态可选「拍摄中 / 待冲洗 / 冲洗中 / 待归档 / 已归档」，
   目录视图会按状态给整行上色。

 第 3 步 · 建文件夹（推荐，也可以在录入时一起做）
   在编辑 / 新增条目窗口的底部有两个按钮：
     「📁 创建文件夹」   按你填的信息自动生成这一卷的文件夹
                         （例如 124_index 1234_FOMAPAN 100_261013）
     「📁 添加子文件夹」 勾选要建的标准子文件夹
   已经存在的子文件夹会自动置灰、不可勾选；点顶部「全选可创建项」再点
   「创建选中的」即可一次建好。
   注意：点「创建文件夹」「添加子文件夹」会**立刻**在硬盘上生效（新增条目时也一样）。
   如果接着点「取消」退出编辑窗，刚建的文件夹会被移入废纸篓（可恢复）、刚改的名字会
   改回去，条目信息也不会保存 —— 相当于这一步没发生过。

     010_scan      扫描原片 —— 店扫 / 平板扫出来的原始文件
     011_scanPost  扫描后期 —— 修图调色后导出的成品
     020_cam       翻拍原片 —— 用相机 / 手机翻拍的原始文件
     021_camPost   翻拍后期 —— 翻拍后修图导出的成品

   ★ 如果你只有扫描件（大多数人都是这样），只勾 010_scan 就够了。

 第 4 步 · 把照片移进来
   最后再把要整理的照片移动到对应的子文件夹里：
     · 只有扫描件    → 全部放进 010_scan
     · 还有翻拍件    → 翻拍原片放进 020_cam
     · 做过后期的    → 成品放进 011_scanPost / 021_camPost
   放好之后回到网页，点该行的「预览」就能看到图片了。

   提示：先把文件夹建好、再移照片，比反过来省事 —— 顺序反了也不会出错，
   只是要自己手动建文件夹。

【图片是怎么被找到的】
录入日期后会按约定自动拼出胶卷文件夹名；点某行的「预览」即可看该卷图片，点图看大图。

【导出可打印索引】
点「🖨 导出 Index Print」，勾选胶卷 → 开始生成，会在 000_INDEX PRINT/ 下每卷生成一个 docx。

【数据与备份】
· 数据库：assets/films.xlsx（可以用 Excel 打开查看，但网页改数据前请先关掉 Excel）
· 设置：assets/settings.json
· 备份：assets/backup/（自动保留若干份，需要时可直接复制回去还原）
· 日志：assets/log/

【重要提醒】
· 在网页里增删改时，请先关闭正在打开 films.xlsx 的 Excel，否则写入可能被拒绝或被覆盖。
· 若你自己改代码：改了 build_html.py 要重新运行它生成 index.html；改了 worker.py 要重启服务。

【放进「应用程序」—— 用 Spotlight / 启动台秒开】

发布包里的  Film Index Page.app  就是一个标准的 macOS 应用。

■ 怎么装
   把它拖进「应用程序」文件夹即可。

■ 怎么打开
   按 Cmd + 空格 输入 film 回车，或者到「启动台」点图标。
   软件图标是米色底 + 珊瑚色胶卷暗盒。

■ 启动逻辑（第一次会问你一次）
   · 第一次打开：软件不知道你把「胶卷索引信息」文件夹放在哪，会弹出一个
     文件夹选择框，让你指过去 —— 选中那个里面有 010_启动Mac.command 和
     assets 文件夹的目录即可。选好之后会自动记住。
   · 以后打开：直接用记住的位置，秒开，不再询问。
   · 如果哪天你把软件目录搬了地方（换硬盘、改文件夹名）：软件会检测到找
     不到，自动重新弹框让你选，不需要手动改任何配置。
   · 也可以把 Film Index Page.app 直接放在「胶卷索引信息」文件夹里面 ——
     这样它能自己认出位置，连第一次的选择都省了。

■ 怎么关闭
   软件会在一个终端窗口里运行本地服务。关掉那个窗口 = 停止服务。
   不会在后台留下进程。

■ 如果 macOS 提示「无法打开，因为来自身份不明的开发者」
   这是因为从网上下载的 .app 会被系统加上隔离标记。解决办法：
   在「应用程序」里右键点击 Film Index Page.app → 选择「打开」，
   在弹窗里再点一次「打开」。之后就能正常双击打开了。
